# Global Red List of Coral Reef Ecosystems – Explorer

Interactive explorer for the first IUCN Red List of Ecosystems assessment of the world's coral reefs: 127 coral reef ecoregions in 10 regions.

**Explorer:** https://globalcoralreefrle.github.io/CoralreefsRLE/

This repository also contains:
- Global methods report (PDF)
- Results by ecoregion (PDF)
- Acknowledgements: authors, contributors, data providers and funders (PDF)
- Two-page regional summaries (`2pagers/`)

Full regional reports are available as preprints on EcoEvoRxiv.

IUCN Red List of Ecosystems – https://iucnrle.org
